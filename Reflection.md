# Reflection


## 1. How AI Tools Supported My Process and How I Used Them Ethically

AI tools supported my work by helping me organize the README structure, improve Markdown and R Markdown formatting, refine wording, and review the documentation for clarity. ChatGPT was especially useful for turning the assignment requirements into clear sections and suggesting improvements after each Seed, Refinement, and Critique/Validation prompt.

I used AI as a documentation and formatting assistant rather than accepting its output without review. I checked the final README in GitHub, knitted the R Markdown file in Posit Cloud, reviewed the generated HTML output, and confirmed that the R calculations were correct. I also disclosed the use of ChatGPT and the main prompts used for README development.



## 2. Strengths and Weaknesses of AI-Assisted Documentation Workflows

One strength of AI-assisted documentation is that it can make the writing and organization process faster. AI helped create a clear structure for the README and R Markdown documentation and suggested improvements to reduce repetition and make the content easier to read.

A weakness is that AI-generated content still needs careful verification. Formatting suggestions may not always match the required file type or assignment instructions, and AI can suggest details that need to be checked against the actual project. For this reason, I reviewed the final Markdown structure, code chunks, and rendered output before considering the documentation complete.



## 3. Ethical Practices: Attribution and Validation

I applied ethical AI practices by clearly identifying ChatGPT as the AI tool used and documenting the main prompts used to complete this assignment. I also reviewed and revised the AI-generated output instead of using it without checking.

Validation was an important part of the process. I verified that the README rendered correctly in GitHub and knitted `ScriptDocumentation.Rmd` in Posit Cloud to confirm that the headings, R code chunks, and outputs worked correctly. I also verified that the five sales values produced `total_sales` of 710 and `average_sales` of 142. These checks helped ensure that the final documentation was accurate and that I remained responsible for the submitted work.
